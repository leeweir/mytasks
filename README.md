# Tasks

本地 Markdown 待办应用，支持 macOS 26。每个 `.md` 文件是一份清单；文件夹就是任务库，不使用私有数据库。

实现采用 Tauri 2 / Rust、React / TypeScript 和 CodeMirror 6。窗口使用系统 WKWebView；文件监听、通知、菜单和 PDF 打印使用 macOS API。不是 SwiftUI / TextKit 工程，不需要完整版 Xcode。

## 运行

开发需要 Node.js 22.12+、Rust stable 和 Xcode Command Line Tools。

```sh
npm ci
npm run tauri -- dev
```

仅运行 `npm run dev` 会启动前端服务器，浏览器里没有文件系统和通知等原生能力。

构建本机架构的应用：

```sh
npm run tauri -- build --bundles app
open src-tauri/target/release/bundle/macos/Tasks.app
```

可将 `Tasks.app` 拖进 `/Applications`。当前用于个人本机运行，没有 Developer ID 签名、公证、自动更新或 App Sandbox。

## 使用

1. 首次启动选择任务文件夹。应用递归读取其中的 `.md` 文件；隐藏目录和 `attachments/` 不参与任务索引。
2. 按 `⌘N` 新建清单，输入 Markdown。停止输入约一秒自动保存；退出前也会保存待写入的内容。
3. 侧栏提供今天、未来七天、已完成、标签和文件树。右键文件或目录可以重命名、移动到废纸篓；空白处可以新建文件夹。
4. 在汇总列表中勾选任务，或点击字段徽章修改日期、提醒、优先级和重复规则；修改会写回源文件。
5. 搜索框扫描全部清单正文，点击结果跳到对应行。

“今天”包含今天到期、已过期，以及今天有提醒的未完成任务。任务先按截止日期、再按优先级排序。标签支持 `#工作`、`#工作/项目` 等层级形式。

### Markdown 格式

字段沿用 Obsidian Tasks 语法。提醒用 `⏰ YYYY-MM-DD HH:mm`，按本地时区解释。

```markdown
# 工作

- [ ] 整理资料 #工作 ⏫ 📅 2026-10-05 ⏰ 2026-10-05 09:00
- [ ] 周报 #工作 🔁 every week 📅 2026-10-09
- [ ] 发布
    - [ ] 检查文案
    - [ ] 更新截图

## Done

- [x] 已处理 ✅ 2026-10-03
```

完成父任务会一并勾选子任务。已完成的顶层任务约三秒后连同子任务移到文件底部 `## Done`；延迟期间可以取消勾选。重复任务在原位置生成下一次实例，旧实例正常归档。支持天、周、月、年、每 N 天、指定星期和月内日。

### 编辑与补全

- 光标所在行显示源码，其他行实时预览；表格在光标进入后显示源码。
- 支持标题、粗斜体、行内代码、代码块、复选框、字段徽章、链接、图片、表格、引用和分割线。
- 输入 `@` 触发中英文补全，例如 `@明天`、`@tomorrow`、`@提醒 明天9点`、`@每周一`、`@高`。用方向键选择，回车确认，Escape 取消。
- 拖入或粘贴图片会复制到任务库的 `attachments/`，插入相对路径。不会移动原图片。
- 浅色 / 深色外观跟随系统。
- 搜索框支持中文输入法：拼音组合期间保留输入，选词确认后再更新结果；Escape 在组合期间交给输入法处理，非组合期间清空搜索。

### 外部修改与冲突

应用通过 FSEvents 监听任务库。编辑器没有未保存内容时自动载入外部修改；本地有改动时暂停自动保存，询问保留本地还是磁盘版本，不会自行合并。

清单删除进入系统废纸篓。没有内置同步、备份或版本历史；请自行备份任务文件夹。

### 提醒

提醒通过 `UNUserNotificationCenter` 预先注册；系统负责已注册提醒的送达，不需要应用保持运行。重复任务的下一次提醒要在完成当前实例、生成新实例后注册。

首次使用需要允许通知。若拒绝，请在“系统设置 → 通知 → Tasks”中开启后重新启动应用。系统拒绝通知时，应用会报告排程错误，不会把未注册的提醒当作成功。

本机验证时系统返回了 `Notifications are not allowed for this application`，因此**尚未验证退出后的实际通知送达**。通知权限和系统专注模式会影响提醒显示。

### 导出

通过当前清单右上角“导出”或 File 菜单导出：

- **PDF**：系统 WebKit 排版，A4 自动分页。
- **HTML**：本地图片内嵌，保留远程图片 URL。
- **Markdown**：副本中的相对链接按导出位置重新计算；图片仍在原任务库，不会另复制一套附件。

### 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘N` | 新建清单 |
| `⌘⇧N` | 新建文件夹 |
| `⌘F` | 全文搜索 |
| `⌘↩` | 完成 / 取消当前任务 |
| `⌘1` / `⌘2` | 今天 / 即将到期 |
| `⌘3` / `⌘4` / `⌘5` | 标签 / 已完成 / 清单 |
| `⌘⇧E` | 当前清单导出 PDF |
| `⌘Z` / `⌘⇧Z` | 编辑器撤销 / 重做 |

关闭窗口会隐藏窗口，点击 Dock 图标可重新打开；`⌘Q` 保存后退出。

## 验证

```sh
npm test
cargo test --manifest-path src-tauri/Cargo.toml
```

当前验证通过 205 个 TypeScript 测试和 5 个 Rust 测试。核心测试覆盖 Markdown 解析与字段修改、子任务联动、重复日期、完成归档、日期补全、聚合查询和搜索；Rust 测试覆盖文件路径、附件命名、排除规则和提醒日期校验。

原生窗口冒烟已验证新建清单、搜索跳转、移到废纸篓、自动保存、外部刷新、冲突选择、重复任务生成、父子任务完成、中英文补全、图片预览、深色外观及三种导出。150 行清单的 PDF 导出为四页，首尾任务均可提取。

中文搜索通过原生 WKWebView 的 `NSTextInputClient` 接口验证 `ni → nihao → 你好`，未残留拼音。浏览器 IME 回放另覆盖 Escape 取消组合、保存延迟期间继续输入、旧搜索失效、搜索跳转和逐字删除。

正式 `.app` 已在关闭 Vite 开发服务器后独立启动验证。生产构建有非阻塞的 JavaScript chunk 超过 500 kB 提示。

## 代码布局

- `src/core/`：不依赖 UI 的解析、任务变更、日期与查询逻辑。
- `src/editor/`：CodeMirror 实时预览、图片、徽章和补全。
- `src/app/`：任务库索引、编辑会话、冲突处理、视图和导出转换。
- `src-tauri/src/`：文件系统、FSEvents、系统通知、原生菜单和 PDF 打印。
